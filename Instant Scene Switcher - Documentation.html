01 Overview

Instant Scene Switcher is a free Unity Editor extension that lets you switch between scenes in your project instantly — directly from the Unity toolbar or via a keyboard shortcut. No more digging through the Project window or navigating menus to open a scene.

▼
Toolbar Dropdown
Scene selector always visible in the Unity toolbar. One click to switch.
⚡
Keyboard Shortcut
Ctrl+Alt+S opens a quick-switch popup from anywhere in the Editor.
☍
Preset System
Group scenes into named presets. Switch whole sets with one click.
⚙
Build Settings Sync
The default preset mirrors your Build Settings automatically.

02 Opening the Window

Go to Tools → Saad Khawaja → Instant Scene Switcher in the Unity menu bar.

Note The window is the main control panel for managing presets and scenes. You do not need it open to use the toolbar dropdown or keyboard shortcut — those work at all times.

The window is split into two panels:

  • Presets (left) — list and manage your scene presets
  • Scenes (right) — view and edit scenes in the selected preset

03 The Toolbar Dropdown

After installing the plugin, a scene selector dropdown appears in the Unity toolbar (top-right area, next to Layers and Layout).

  • The dropdown shows all scenes in the currently active preset
  • Click a scene name to switch to it (you will be prompted to save unsaved changes)
  • If no scenes are in the active preset, the dropdown shows "No Scenes Added" — hover it to see a tooltip explaining how to add scenes
  • The dropdown is disabled during Play Mode
Tip The toolbar dropdown always reflects the active preset. To change which scenes appear, apply a different preset from the Instant Scene Switcher window.

04 Presets

A preset is a named collection of scenes. The plugin ships with one built-in preset and lets you create as many custom presets as you need.

Built-in: Build Settings

The ★ Build Settings preset (shown at the top of the preset list) automatically mirrors the enabled scenes in your Unity Build Settings (File → Build Settings). It is read-only — you cannot manually add or remove scenes from it here; manage those in the Build Settings window instead.

Creating a Custom Preset

  1. Open the Instant Scene Switcher window
  2. In the Presets panel on the left, type a name in the text field at the bottom
  3. Click Create

The new preset appears in the list and is immediately selected.

Duplicating a Preset

  1. Select any preset in the list
  2. Click Duplicate

A copy is created named "Original Name Copy" (or "Copy 2", "Copy 3" if that name is taken). Useful for creating variations of your current workflow.

Deleting a Preset

Click the – button to the right of any custom preset. A confirmation dialog appears before deletion. The Build Settings preset cannot be deleted.

Applying a Preset

Selecting a preset in the list only inspects it. To make it active so the toolbar dropdown shows its scenes:

  1. Select the preset you want to use
  2. Click the large green Apply Preset button at the bottom of the window
Info The Apply button shows "Already Using" when the selected preset is already active. The active preset is also highlighted in green in the preset list.

05 Managing Scenes in a Preset

The Scenes panel on the right shows the scenes in the currently selected preset.

Adding Scenes

Method 1 — Object Picker

Use the scene picker field at the bottom of the Scenes panel. Click the circle icon, pick a scene asset, then click + Add.

Method 2 — Drag and Drop

Drag one or more scene assets from the Project window directly onto the Instant Scene Switcher window. A dark overlay appears to confirm the drop target.

Note Scenes cannot be added to the Build Settings preset here. Manage those in File → Build Settings.

Removing Scenes

  • Right-click a scene in the list → Remove from Preset
  • Or select the scene and click the – button at the bottom of the list

Reordering Scenes

Drag scene rows up or down in the list to reorder them. The toolbar dropdown reflects the new order immediately.

Clicking a Scene in the List

Clicking a scene name in the list pings and selects it in the Project window — useful for quickly navigating to a scene file without opening it.

06 Quick Switch Popup

Press Ctrl + Alt + S anywhere in the Unity Editor to open the Quick Scene Switch popup.

The popup shows all scenes from the active preset in a scrollable list.

Input Action
↑ / ↓ Move selection up / down
Enter Load the selected scene
Esc Close without switching
Double-click Load the clicked scene immediately

You can also use the Load and Close buttons at the bottom of the popup.

Fallback If no scenes are available in the active preset, the popup automatically falls back to your Build Settings scenes.

07 File Structure

The plugin lives entirely in the Editor folder and has no runtime overhead — none of its code is included in your built game.

Instant Scene Switcher/ └── Editor/ ├── InstantSceneSwitcher.cs — Main window, settings data, quick popup ├── SceneSelectorToolbar.cs — Unity toolbar dropdown injection └── ToolbarCallback.cs — Toolbar hook utility

Settings are saved to ProjectSettings/InstantSceneSwitcherSettings.asset and are tracked in version control automatically alongside the rest of your project settings.

08 Tips

Multiple Developers Settings live in ProjectSettings/, so your whole team shares the same presets when committed to source control. No extra setup needed.
Fast Iteration Create a "Current Feature" preset with only the 2–3 scenes relevant to what you are building — so the toolbar dropdown stays minimal and you don't scroll past unrelated scenes.
Build Verification Switch to the Build Settings preset before doing a build to confirm you are testing with the correct scene set.
